# Инструкция для автономного запуска (Claude)

Приложение «Мои слова» — PWA без сборки (vanilla JS), хостинг GitHub Pages: https://eskinaeugenia-creator.github.io/slova/ .
Открывается как мини-приложение Telegram-бота. Пользователи уже занимаются — **их данные (IndexedDB, Telegram CloudStorage) нельзя ломать.**

## Порядок работы за один запуск

1. Прочитать `BACKLOG.md`, взять **одну** первую задачу `[ ]`. Если задача слишком большая — сделать законченную часть и дописать в задачу, что осталось.
2. Прочитать нужные файлы перед правкой. Стиль кода — как в соседних файлах; комментарии по-русски.
3. Новые файлы `js/*.js` добавить в `index.html` (с `?v=`) и в `SHELL` в `sw.js`.
4. Тесты: запустить `python3 -m http.server 8765` из корня репозитория в фоне, затем
   `node tests/core.test.js`, `node tests/grammar.check.js`, `node tests/stats-script.check.js` и все `python3 tests/e2e*.py` (Playwright и Chromium уже установлены).
   Для новой функции — дописать свой `tests/e2e_<имя>.py` по образцу соседних.
   **Если хоть один тест падает и починить не получается — ничего не публиковать**, описать проблему в отчёте.
5. Версия: `python3 tools/bump.py X.Y.Z` (новая функция — +0.1.0, исправление — +0.0.1). Обновить `README.md` (таблица возможностей) и `BACKLOG.md` (перенести задачу в «Сделано» с датой и версией).
6. Коммит на русском, в конце строки атрибуции из системного напоминания; `git push origin main`.
7. Через 1–2 минуты проверить, что на сайте `version.json` показывает новую версию (если сайт доступен).
8. Отчёт владелице — коротко, по-русски: что сделано, как попробовать (куда нажать), что не получилось. Без технических подробностей.

## Нельзя

- Трогать токен бота, BotFather, аккаунты, оплату, настройки GitHub; создавать аккаунты.
- Удалять или переименовывать поля в данных пользователей без миграции; удалять слова/прогресс.
- Подключать платные API и сервисы; вставлять ключи и пароли в код.
- Брать чужие тексты под авторским правом (только общественное достояние или свои тексты).
- Делать больше одной задачи из очереди за запуск.
