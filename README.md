# Мои слова — личный тренажёр английских слов

Приложение-сайт (PWA) для iPhone и компьютера. Без регистрации, без сервера, без платных сервисов. Словарь и прогресс хранятся на устройстве.

## Архитектура

- **Чистый сайт без сборки**: HTML + CSS + JavaScript, без фреймворков. Его легко разместить бесплатно (GitHub Pages) и в будущем открыть как Telegram Mini App, потому что это тот же сайт.
- **Данные** лежат в IndexedDB браузера: слова, наборы, история ответов, занятия. У формата данных есть номер версии (`format: 1`), при обновлениях данные мигрируют, а не стираются.
- **Офлайн**: service worker кэширует само приложение. Данные кэшем не затрагиваются.
- **Повторения**: алгоритм **FSRS-4.5** с параметрами по умолчанию (тот же, что в Anki). Два отдельных расписания для каждого слова:
  - **узнавание**: видите слово и понимаете его;
  - **вспоминание**: сами пишете слово.
- Файлы:
  - `js/core.js` — логика: разбор списков, проверка ответов, FSRS, план дня;
  - `js/db.js` — хранилище;
  - `js/app.js` — каркас, «Сегодня», «Словарь», карточка;
  - `js/add.js` — добавление и импорт;
  - `js/train.js` — тренировки;
  - `js/prefs.js` — прогресс, настройки, резервные копии.

## Бесплатные решения и их ограничения

| Что | Как | Где работает | Ограничения |
|---|---|---|---|
| Озвучка обычная и медленная | Голоса устройства (Web Speech) | Локально, без интернета на iPhone | Качество зависит от установленных голосов. В Chrome на компьютере голоса «Google…» требуют сеть |
| Повторения, тренировки, импорт файлов, бэкап | Код приложения | Локально | — |
| Неправильные глаголы | Встроенный список, около 85 глаголов | Локально | Только распространённые |
| Перевод слова и примера | MyMemory | Бесплатный внешний сервис, только по кнопке | Около 5000 символов в день, машинное качество |
| Часть речи, пример, транскрипция | Free Dictionary (dictionaryapi.dev) | Бесплатный внешний сервис, только по кнопке | Примеры бывают сложнее уровня A1 и есть не у всех слов |
| Эмодзи-ассоциация | Встроенный словарь около 260 частых слов, плюс поле `emoji` из ответа Claude | Локально, сразу, без интернета | Только частые слова |
| Картинки — **подбираются сами** после сохранения слова | Wikimedia Commons (основной), Openverse (запасной) — свободные лицензии | Бесплатные внешние сервисы, в фоне; без сети ждут и продолжают | Подбор по ключевым словам: картинка помечается «подобрана автоматически — проверьте»; есть «Другая», «Убрать», «Своё фото». Для абстрактных слов Claude даёт запрос-сцену (`rent` → `apartment keys`). Точные лимиты анонимных запросов источники не публикуют — при сигнале «слишком часто» подбор ставится на паузу на 30 минут |
| Напоминание | Файл календаря `.ics`, ежедневное событие | Календарь iPhone или компьютера | Это не push-уведомление |
| Перенос iPhone ↔ компьютер | Резервная копия JSON → «Восстановить → Объединить» | Вручную | Это не автоматическая синхронизация |

Что потребует отдельного сервиса или настройки (следующие этапы):
- push-уведомления — нужен сервер для отправки;
- автосинхронизация — Supabase, бесплатный тариф: неактивный проект ставится на паузу, нужен вход;
- распознавание речи и аудиофайлов.

## Как пользоваться

**Открыть.** Откройте адрес сайта в Safari на iPhone или в браузере на компьютере.

**Добавить на экран iPhone.** В Safari нажмите «Поделиться» → «На экран „Домой“» → «Добавить». Открывайте приложение с иконки: так оно работает без интернета, а данные не удаляются через 7 дней неактивности, как бывает в обычной вкладке Safari.

**Первые слова:**
- **Одно**: «Добавить» → впишите слово → «Подсказать перевод и пример» (или впишите сами) → «Сохранить».
- **Списком**: «Добавить» → «Список» → вставьте строки вида `rent — снимать` → «Разобрать и проверить» → «Сохранить».

**Резервная копия.** «Настройки» (шестерёнка) → «Сохранить резервную копию». На iPhone откроется меню «Поделиться» → «Сохранить в Файлы» (лучше в iCloud Drive). Приложение само напомнит, если копии давно не было.

**Перенос на компьютер.** На компьютере «Настройки» → «Восстановить из файла» → «Объединить».

## Проверки (автотесты в headless Chromium, экран 375 и 320 px)

- Логика (Node), 14 тестов: разбор 50 строк со смешанными разделителями, дубли, проверка ответов, FSRS, план после пропуска, ответ Claude (JSON/TSV), CSV.
- Автокартинки, 15 проверок (ответы Wikimedia подменены тестовыми, т. к. внешняя сеть в среде разработки закрыта): эмодзи сразу, фото после сохранения и после импорта, автор/лицензия, «Другая», «Убрать», своё фото не перезаписывается, без сети — ожидание и продолжение, выключатель в настройках; плюс вопрос имени при первом запуске.
- Telegram, 17 проверок (облако Telegram имитировано): имя из Telegram, запись в облако, лимит 4096, кнопка «Назад», продолжение занятия после перезапуска, второе устройство получает слова и прогресс, правка и удаление доходят до другого устройства, у другого пользователя пустой словарь, вне Telegram ничего не меняется.
- Сценарии в браузере, 50 проверок:
  - добавление слова, выражения, черновика;
  - импорт 50 строк;
  - изменение перевода и комментария;
  - повторное открытие;
  - верный, неверный ответ и опечатка;
  - даты повторения;
  - повтор в тот же день не меняет расписание;
  - экспорт, удаление, восстановление;
  - работа без сети;
  - нет горизонтальной прокрутки на всех экранах.
- Не проверено автоматически: голоса на реальном iPhone, установка на экран «Домой», онлайн-сервисы (в среде разработки внешняя сеть закрыта). Это нужно проверить вручную после публикации.
